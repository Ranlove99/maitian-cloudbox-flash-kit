00先搞清楚这台机器是什么

麦田云盒 1S Plus 不是普通电视盒子，它是两块完全独立的板子塞进一个白色圆柱壳里，共用一个电源。这个设计决定了刷机时的所有坑：

上半部分 · 路由板
MT7621 + 128MB DDR3
OpenWrt 系统 · WiFi 6 · 866Mbps
3 个千兆网口（1 WAN + 2 LAN）
下半部分 · 盒子板
Amlogic S905X3 · 4 核 A55 @2.0GHz
4GB DDR4 + 128GB eMMC · Android TV
HDMI / USB 3.0 / USB 2.0 / 复位孔
最容易踩的坑

盒子板没有独立无线网卡。它的网络是在机箱内部接到路由板 LAN 口的。所以你给盒子板刷了 Armbian 之后，不要指望它能连 Wi-Fi，必须靠网线（接路由板，或直接接上级路由器）。

换句话说，这两块板的命运是绑在一起的：路由板挂了，盒子板就没网；反过来盒子板刷死，路由板照常工作。刷机时只动你要动的那个，别一把梭。

01选哪条路线

路线 A · 主流玩法

盒子板 → Armbian

把安卓换成 Debian 底子的 Linux，当轻量 NAS、下载机、Docker 小主机、内网服务节点。128GB eMMC 是最大价值所在。

社区已有实测：S905X3 平台跑 Armbian 26.02 trixie + 内核 6.18，连续稳定运行一个月以上。

路线 B · 轻度

盒子板 → 纯净 Android TV

只想当电视盒子用，受不了原厂那套 PCDN / 广告系统。刷 slimBOXtv 系 ATV 固件，界面干净、能装第三方 App。

其实这就是路线 A 的前置步骤：刷完 ATV 停下，就是路线 B。

重要顺序

不管你最终要 Armbian 还是 ATV，第一步都是先线刷安卓 ATV 固件。原厂固件锁了引导，直接插 U 盘是起不来的；刷入第三方 ATV 之后，它的 u-boot 才支持从 U 盘引导，Armbian 才能跑起来。

路由板的 OpenWrt 出厂就是原厂定制版，日常用不需要刷，第 8 节单独说。

03线刷安卓 ATV 打底

这一步的目标不是"用安卓"，而是换掉原厂 u-boot，解锁 U 盘启动能力。刷完你就有了一个干净可用的 ATV 系统，也是后面所有操作的跳板。

1

装工具、装驱动

安装 Amlogic USB Burning Tool。Win 10 / 11 第一次打开会提示驱动安装，必须点"是"允许；如果安装时报驱动签名错误，先临时禁用"驱动程序签名强制"再装。

2

导入固件并设置选项

菜单「文件 → 导入烧录包」选择 ATV 的 .img，等待校验完成。然后严格按下表设置：

选项设置原因
擦除 flash普通擦除（勾选）清掉原厂分区表，必须
擦除 bootloader不勾勾了极易变砖
覆盖 key不勾会清掉 MAC / 序列号等唯一信息
3

进入 MaskROM：短接 + 上电

按顺序操作，顺序错了识别不到设备：

  1. 盒子断电（拔电源）
  2. 短接神器插进盒子 HDMI 口
  3. 双公头 USB 线一头接电脑（插机箱后置 USB 口，供电更稳），一头接盒子的 USB 2.0 口（靠近 HDMI 那个）
  4. 给盒子上电
  5. 烧录工具提示「连接成功」后，立即拔掉短接神器
4

开始烧录

点「开始」，进度条走完（约 3–8 分钟），提示 Success 后点「停止」、拔线、接 HDMI 通电。首次开机较慢，等 2–5 分钟进系统。

阶段成果

到这里，如果你只想当电视盒子，已经可以收工了：装个当贝 / Emotn 桌面，收工。要继续上 Armbian，往下走。

04写 Armbian 到 U 盘

1

选对镜像

到 ophub 的 Releases 页面，找文件名里带 amlogic_s905x3 的镜像，后缀 .img.gz。不要选 s905x2 / s905l3a，那些是别的芯片，dtb 完全不匹配。

Debian 版本建议 bookworm（trixie 在新设备上偶有兼容小问题；不过实测帖里用的就是 trixie，能跑）。带 server 的是无桌面版，占空间小，推荐。

2

用 Rufus / balenaEtcher 写入

选 U 盘 → 选镜像 → 开始。写完 Windows 会弹「需要格式化」的提示，点取消，那是 Linux 分区，Windows 读不懂很正常。

3

改 dtb（关键一步）

U 盘里有个 FAT32 的 BOOT 分区，Windows 能直接打开。进去找到 extlinux/extlinux.conf，用记事本打开，找到 FDT 那一行：

# 改之前（默认，对应百兆网口的 X96-Air，网口会不通）
FDT /dtb/amlogic/meson-sm1-x96-air.dtb

# 改之后（4GB 内存 + 千兆网口，实测稳定）
FDT /dtb/amlogic/meson-sm1-x96-max-plus-oc.dtb

不想手改也行——先按默认启动，进系统后用 armbian-install 选 dtb，一样能成。但如果启动后有线网口不通，就回来改这里。

为什么是 x96-max-plus

S905X3 + 4GB 内存 + 千兆网口的硬件组合，最接近的公版设计就是 X96 Max+。带 -oc 后缀是超频版 dtb（CPU 主频放得更开），4G 内存机型用它最合适。备选：meson-sm1-x96-max-plus.dtb（不超频）、meson-sm1-hk1box-vontar-x3-oc.dtb。

05从 U 盘启动

四种方式，从上到下按省事程度排。第一种成功率高且不用拆机，优先试。

方式一：APK 一键重启（推荐）

在 ATV 系统里装 Reboot to LibreELEC.apk，插上写好系统的 U 盘，打开这个 App，弹窗点「OK」，盒子重启后直接进 U 盘里的 Armbian。

方式二：复位孔

盒子断电 → 插 U 盘 → 用卡针顶住机身背面的复位小孔不放 → 上电 → 保持 5 秒左右再松手。

方式三：ADB 命令

ATV 里开启 USB 调试 / 网络调试，电脑上执行：

adb connect 192.168.x.x
adb shell reboot update

方式四：拆机短接

前三种都不行才用这招。拆开底盖，找到 eMMC 颗粒附近标注 SW / KEY 的两个焊盘（或直接短接 eMMC 任意两个数据脚），镊子夹住保持短接，同时上电。

看到什么算成功

HDMI 接上显示器，屏幕滚过一堆启动日志，最后停在 armbian login: 提示符——这就对了。此时系统还跑在 U 盘上，eMMC 里的东西一个字节都没动。

06装进 eMMC

1

登录

账号 root，密码 1234。首次登录会强制改密码，然后问你要不要创建普通用户——按 Ctrl+C 跳过，直接用 root 最省事。

2

先确认能上网

网线接上（接路由板 LAN 口，或直接接你家路由器），执行：

ip a
ping -c 3 baidu.com

拿到 IP 且能 ping 通再往下走。不通就 nmtui 手动配。建议这一步就把 IP 记下来，之后 SSH 用它。

3

运行安装脚本

armbian-install

脚本会列出设备列表（ID / SOC / MODEL / DTB 四列）。别死记 ID 数字，按机型名找，因为 ID 会随版本变动。在 S905X3 段里找：

MODELDTB说明
X96-Max+ (OverClock)meson-sm1-x96-max-plus-oc.dtb首选，实测稳定一个月
X96-Max+meson-sm1-x96-max-plus.dtb不超频，更保守
HK1-Box (OverClock)meson-sm1-hk1box-vontar-x3-oc.dtb备选，与 ATV 固件同源
X96-Max+ 100Mbmeson-sm1-x96-air.dtb别选，只有百兆网口

接着选文件系统：1 = ext4（推荐，稳、兼容好）；2 = btrfs（要快照才用）。

4

等待 → 关机 → 拔 U 盘 → 重启

屏幕会滚过写 bootloader、重建分区表、格式化 BOOTFS / ROOTFS 的日志，约 2–5 分钟。看到 Installation successful 后执行：

poweroff

拔掉 U 盘，重新上电。这次系统从 eMMC 启动，128GB 全部归你。

验收

重新登录后跑 df -h 看根分区，应该是 100GB 以上；htop 能看到 4 核 A55、约 3.6GB 可用内存；uname -a 内核带 -ophub 后缀。都对就说明装好了。

07刷完必做的配置

换国内源（不换下载慢到怀疑人生）

armbian-apt      # 按提示选清华 / 腾讯源，自动改 sources.list
apt update

装软件

armbian-software          # 软件中心，一键装 Docker / 1Panel / CasaOS 等
armbian-software -u       # 先更新一次软件列表

加虚拟内存

4GB 内存跑 Docker 有时吃紧，用 eMMC 空间换 swap（参数单位 GB）：

armbian-swap 2

固定 IP

盒子板没有 Wi-Fi，IP 靠路由板 DHCP 分配，重启可能变。两种做法：登录路由板后台做 DHCP 静态绑定，或在 Armbian 里写死：

nmtui      # 图形化改 IPv4 为 Manual，填 IP / 掩码 / 网关 / DNS

顺手优化

# eMMC 定期 TRIM，延长寿命
fstrim -av
echo -e '#!/bin/bash\nfstrim -av' > /etc/cron.weekly/fstrim
chmod +x /etc/cron.weekly/fstrim

# 关掉用不到的服务，省内存
systemctl disable --now bluetooth ModemManager avahi-daemon
LED 屏 / 面板显示

如果机身前面板有小显示屏不亮，跑 armbian-openvfd 按提示调；不同批次的面板驱动不一样，调不出来也不影响系统。

08路由那一半（MT7621）

路由板出厂跑的就是 OpenWrt，只不过管理界面被换成了厂商定制页。绝大多数人不需要重刷，改改就行。

先登进去看看

项目值
管理地址http://192.168.5.1/cgi-bin/luci/
默认账号admin
默认密码123456

拿 root 权限

社区帖里给出的路径是：进原厂系统的安全模式 → 修改 root 密码 → 拿到 root，然后可以删掉厂商页面、装官方 LuCI。拿到 SSH 之后：

ssh root@192.168.5.1
# 登录后可以装官方 LuCI 主题，或直接用 uci 改配置
opkg update
想彻底换固件？先想清楚

路由板的固件不是普通软刷能搞定的——帖子里提到，原厂 root 后的固件需要用编程器刷入（CH341A + 夹子直接读写 Flash 芯片）。这意味着：拆机、夹芯片、备份原固件、刷写，全程没有回滚按钮。而且路由板刷坏，盒子板就彻底断网了。除非你有编程器和明确的目标固件，否则别动。

变砖了怎么办

黑屏、卡 logo、指示灯不亮——大概率是软砖，能救：

  1. 短接神器 + 烧录工具强刷：重新走第 3 节的 MaskROM 流程，把 ATV 固件再烧一遍，90% 的软砖都能回来
  2. 断电大法：拔电源放五分钟再上电，个别偶发故障能自己缓过来
  3. 换 dtb 重来：U 盘阶段起不来，多半只是 dtb 选错，eMMC 里的东西没坏

真正救不回来的是刷错芯片型号的固件（比如把 s905w 的包刷进 s905x3），那会写坏 bootloader，只能上编程器。

10风险与底线

动手前请确认你能接受
  • 短接有硬件风险。镊子滑到旁边的元件上，可能直接送走 eMMC 或 SoC。第一次建议用免拆短接神器，别用镊子硬怼。
  • 原厂系统不可恢复。原厂固件没有公开，128GB eMMC 里的原厂安卓 + PCDN 数据刷掉就没了。
  • 刷机即失去保修。拆机痕迹、封条破损都算。
  • 两块板互相牵连。路由板刷坏 → 盒子板断网；盒子板刷坏 → 路由板照常，但盒子变砖。
  • 中途绝对不能断电。烧录过程中拔线或停电，基本直接变砖。

一句话总结流程

短接进 MaskROM → 线刷 ATV 解锁引导 → 写 Armbian 到 U 盘并改 dtb →
APK 重启进 U 盘 → armbian-install 选 x96-max-plus-oc + ext4 →
poweroff 拔盘重启 → 换源、装 Docker、固定 IP。

还能刷什么

同一套"先刷 ATV 打底、再 U 盘引导装系统"的流程，S905X3 平台还能跑：

  • FnNAS（飞牛） — 想要图形化 NAS 界面，比纯 Armbian 友好
  • OpenWrt（盒子版） — 把盒子板当软路由 / 旁路由
  • LibreELEC / CoreELEC — 只做 4K 播放机，硬解最完整
  • EmuELEC — 复古游戏机，S905X3 性能绰绰有余

换系统只需重写 U 盘，不用再动 bootloader，比第一次刷轻松得多。
