00三个必须先知道的事

如果你看过 Armbian 那份教程，请注意这里有三处**完全相反**的地方。这是刷飞牛最常见的翻车点。

差异一

不是 root / 1234 登录

Armbian 是控制台 root / 1234 登录后跑安装脚本。飞牛是浏览器打开 IP:5666 创建账号，再到「系统设置 → SSH」手动开 SSH，才能进终端。

差异二

改的是 uEnv.txt，不是 extlinux.conf

Armbian 改 extlinux/extlinux.conf 的 FDT 行。飞牛改根目录 uEnv.txt 的 fdtfile= 行。改错文件等于没改。

差异三 · 最重要

飞牛第一次启动时，如果 dtb 不对，网口就不通，拿不到 IP，也就进不了网页。Armbian 至少有 HDMI 控制台可以登录折腾，飞牛是"网页优先"的系统——所以 务必在写完之后、插上之前，先把 uEnv.txt 改好。这一步是整份教程里最不能省的。

还有一点要说清楚：飞牛官方 fnOS 只支持 x86。这里刷的是 ophub 在飞牛官方技术指导下构建的 ARM64 适配版（FnNAS），完整继承官方功能（写入 eMMC、内核在线升级、应用中心），但整体仍带内测性质，功能完整度和稳定性不如 x86 正式版。

01飞牛能干什么、不能干什么

刷完之后，1S Plus 的 4G 内存 + 128G eMMC 会变成一台低功耗 NAS。实际能跑起来的：

能力说明这台机器的表现
私有云盘SMB / WebDAV / FTP / NFS，手机电脑电视互通好用，128G 自带空间 + USB 3.0 外挂硬盘
飞牛影视自动刮削海报、字幕，界面干净无广告能用，但硬件解码大概率不启用，高码率 4K 会卡
飞牛相册人脸识别、智能搜索、支持 iPhone 实况照片能用，首次索引 128G 照片会比较久
DockerqBittorrent、OpenList、AdGuard、Lucky 等4G 内存够跑几个轻量容器，别堆太多
远程访问FN Connect（官方免费版）可用，速度一般
相册 AI / 人脸需要算力能跑但慢，S905X3 没有 NPU
要有心理预期

飞牛 ARM 版是内测阶段的产物。已知问题包括：应用中心里部分应用装不上、个别镜像有"无法创建文件夹"的权限 BUG、部分机型硬件解码不启用。当轻量文件服务器 + 几个小容器很合适，当主力影音 NAS 会失望。

跟 Armbian 那套基本重合，只换一个固件。

Releases 里有几十个镜像，一定要找文件名叫 fnnas_amlogic_s905x3_k*.img.gz 的那个（不带任何后缀的通用版）。带 -x88-pro-x3 后缀的是给另一块板子的，dtb 不通用。看到 s905x2 / s905l3a / s905w 一律跳过。

03打底：线刷 ATV（如果已刷过可跳过）

跟 Armbian 方案完全一样，作用是换掉原厂 u-boot、解锁 U 盘启动。已经刷过 ATV 的机器直接跳到第 4 节。

  1. 装工具：安装 USB Burning Tool，Win10/11 报驱动签名错误就先临时禁用签名强制
  2. 导入固件：选择 ATV 的 .img，等待校验完成
  3. 设选项：擦除 flash 勾选 · 擦除 bootloader 不勾 · 覆盖 key 不勾
  4. 进 MaskROM：断电 → 短接神器插 HDMI → 双公头 USB 接盒子 USB2.0 口和电脑（机箱后置）→ 上电
  5. 松短接：工具提示"连接成功"后立刻拔掉短接神器
  6. 开始烧录：点开始，3–8 分钟到 100%，显示 Success 后停止、拔线、接 HDMI 通电
验证

能正常进安卓桌面、遥控器能用、插网线有网——说明打底成功，可以往下走。

04写镜像 + 改 uEnv.txt

1

下载并写盘

下载 fnnas_amlogic_s905x3_k6.12.41_*.img.gz。用 Rufus 选 U 盘 → 选镜像 → 开始。不需要解压，Rufus 能直接处理 .gz。

写完后 Windows 可能弹「需要格式化」，点取消。

2

改 uEnv.txt（核心一步）

U 盘里有个 FAT32 分区，Windows 能直接打开。找到根目录的 uEnv.txt，用记事本打开，定位 fdtfile= 这一行：

# 改之前（默认指向百兆网口机型，网口会不通）
fdtfile=amlogic/meson-sm1-x96-air.dtb

# 改成这个（4G 内存 + 千兆网口，与 Armbian 方案同一颗 dtb）
fdtfile=amlogic/meson-sm1-x96-max-plus-oc.dtb

保存，安全弹出 U 盘。注意是 amlogic/ 开头的相对路径，不要写成 /dtb/amlogic/...——飞牛的 uEnv.txt 和 Armbian 的 extlinux.conf 路径写法不一样。

没有 uEnv.txt 怎么办

极少数版本可能用别的引导文件。先 ls 一下 FAT32 分区根目录，看有没有 uEnv.txt、boot.scr、extlinux/ 这几个。有 uEnv.txt 就改它；如果只有 extlinux/extlinux.conf，那说明这个镜像沿用了 Armbian 的引导方式，改里面的 FDT 行。

进系统后还能再确认

如果启动后网口通了但设备名不对、或者某个功能异常，SSH 进去后可以查有哪些 dtb 可选：

ls /boot/dtb/amlogic/ | grep sm1

05U 盘启动、找 IP、网页初始化

第一步：让它从 U 盘启动

和 Armbian 一样四种方式，优先用第一种：

方式操作适用
APK 一键重启安卓里装 Reboot to LibreELEC.apk，插 U 盘，点开 App 确认推荐，不用拆机
复位孔断电 → 插 U 盘 → 卡针顶住复位孔 → 上电 → 保持 5 秒备用
ADBadb shell reboot update已开调试
拆机短接镊子短接 eMMC 数据脚 / SW 焊盘后上电兜底

第二步：在路由器里找它

飞牛启动后会自动通过 DHCP 拿地址，主机名是 debian。登录你家路由器后台，在"已连接设备"里找一个叫 debian 的，记下它的 IP。

这台机器的特殊之处

盒子板的网口是接到机内路由板的。如果你把盒子直接接在自家路由器上，就从自家路由找 debian；如果是接在麦田云盒的路由板 LAN 口上，就得登路由板后台 192.168.5.1 去看 DHCP 列表。

找不到 IP 的话，接上 HDMI 看屏幕，启动日志末尾通常会直接打印：

The FnNAS Web UI can be directly accessed at:
http://192.168.1.15:5666

第三步：网页初始化

浏览器打开 http://你的IP:5666，第一次进来是创建页面：

  • 设备名称：随便起，比如 MaitianNAS
  • 超级管理员账号：英文，比如 admin
  • 密码：自己设，记牢——后面 SSH 提权要用它
  • 勾选同意协议 → 进入飞牛
到这一步已经能用了

系统正在 U 盘上运行，网页面板、文件管理、Docker 都能操作。但此时 eMMC 里还是安卓，拔掉 U 盘就回到安卓。要固化，继续下一步。

06装进 eMMC

1

在网页里打开 SSH

左侧「系统设置」→「SSH」→ 打开开关。飞牛的 SSH 默认是关的，不开这一步后面连不上。

2

SSH 连进去提权

用 FinalShell / MobaXterm / 系统自带终端都行：

ssh admin@192.168.1.15      # 换成你的账号和 IP
# 输入你在网页里设的密码

sudo -i                      # 提权到 root，再输一次密码
3

运行安装脚本

fnnas-install

脚本会列出设备表（ID / SoC / Model / DTB 四列）。在 S905X3 段里按机型名找，别记数字，ID 会随版本变：

ModelDTB说明
X96-Max+ (OverClock)meson-sm1-x96-max-plus-oc.dtb首选，与 Armbian 方案实测同款
X96-Max+meson-sm1-x96-max-plus.dtb不超频，更保守
HK1-Box (OverClock)meson-sm1-hk1box-vontar-x3-oc.dtb备选，与打底 ATV 同源
X96-Air / 100Mbmeson-sm1-x96-air.dtb别选，百兆网口
4

选分区大小，然后等

接着会问根分区多大（详见第 7 节）：

  • 1 — 根分区限制在 16GiB，剩余空间留给存储池 ← 128G 机器推荐
  • 2 — 根分区扩展到整盘（脚本的默认建议值）
  • 3 — 保留当前分区表（重装时才有，用于保住 P3 数据）
  • ≥16 — 直接输入一个 GiB 数字，比如 32

选完脚本开始写 bootloader、重建分区、格式化，输出一路滚到 SUCCESS。约 3–8 分钟。

5

关机、拔 U 盘、重新上电

poweroff

拔掉 U 盘，重新通电。这次从 eMMC 启动，浏览器再访问同一个 IP（可能变了，重新在路由里找 debian 或看屏幕），:5666 照常进面板。

验收

SSH 里跑 lsblk，应该看到系统装在 mmcblk*（eMMC）上，而不是 sda（U 盘）。跑 df -h / 看根分区大小跟你选的一致。

07分区怎么选（128G 的关键决策）

这是整份教程里唯一需要你想清楚的地方。选错了要么系统盘吃满 128G、要么以后想扩系统很麻烦。

选法结果适合谁
1（16GiB）系统占 16G，剩下约 105G 可以在飞牛里建成存储空间推荐。纯 NAS 用途，Docker 只跑几个轻量容器
32系统占 32G，剩约 90G 做存储打算装不少 Docker 镜像（镜像很吃系统盘）
2（全盘）128G 全给系统根分区，没有内置存储空间只把 eMMC 当系统盘，数据全靠 USB3.0 外挂硬盘
别顺手敲 2

脚本把 2 标成默认，是因为它的通用逻辑是"有一块盘就全用上"。但飞牛是 NAS，数据要单独建存储空间。选 2 之后你会发现「存储空间管理」里没有可用的内置空间，必须插 U 盘或硬盘才能建存储池——128G eMMC 白白被系统吃掉。

建好之后补一步

装完进网页，「存储空间管理」→「创建」，把剩余空间建成存储池（建议单盘 ext4 或 RAID0 不需要的直通模式）。之后文件、相册、影视、Docker 数据都往这里放。

如果已经选错

重刷 U 盘 → 重走 fnnas-install 即可，选 3（保留分区）或重新选大小都行。eMMC 里的数据会被清掉，所以装系统时别急着往里存东西。

08装完做什么

创建存储空间

「存储空间管理」→ 创建 → 选剩余空间 → 文件系统 ext4 → 完成。这是后面所有功能的地基。

开远程访问

「系统设置 → 远程访问 → FN Connect」，官方基础版免费。在外面用手机也能连回家。

装应用（应用中心）

常用组合，按需装：

应用用途
qBittorrentBT / PT 下载，挂到存储空间
OpenList（原 Alist）聚合各家网盘，统一入口
AdGuard Home全屋去广告 DNS
Lucky内网穿透 + 反向代理 + 自动证书
飞牛影视 / 飞牛相册官方套件，刮削和相册管理

加虚拟内存

4G 内存跑 Docker 容易吃紧，用 eMMC 换 swap（参数单位 GB）：

sudo -i
fnnas-swap 2

更新内核

sudo -i
fnnas-update              # 升到最新
fnnas-update -k 6.12      # 或指定内核系列

更新会自动备份旧内核到 /ddbr/backup。升完起不来，用 fnnas-update -s 恢复。

备份当前系统

sudo -i
fnnas-ddbr                # 输入 b 备份，输入 r 恢复

调教好之后备份一次，以后折腾坏了直接 r 回来，比重新刷 U 盘快得多。

固定 IP

盒子板没 Wi-Fi，IP 靠 DHCP，重启可能变。在自家路由器（或麦田云盒的路由板 192.168.5.1）里做 DHCP 静态绑定，一劳永逸。

10Armbian 还是飞牛

两个都能刷，硬件准备、打底步骤、dtb 选择完全一样，区别只在"装完之后你面对什么"。

Armbian飞牛 FnNAS
上手门槛要会一点命令行网页点点就能用
装系统的入口HDMI 控制台 root/1234浏览器 :5666 建账号 → 开 SSH
改 dtb 的文件extlinux/extlinux.conf 的 FDTuEnv.txt 的 fdtfile
文件共享自己装 Samba / NFS内置，开箱可用
影视刮削装 Jellyfin / Emby内置飞牛影视
相册装 Immich 等内置飞牛相册
稳定性成熟，社区跑了很久内测阶段，偶有 BUG
可定制性极高，想怎么改怎么改受限于官方框架
适合想学 Linux、要跑自定义服务只想有个好用的家用 NAS
两个都要？

可以。U 盘就是个"移动系统"，eMMC 里装飞牛，U 盘里放 Armbian，想换的时候改启动顺序即可——不用重刷 eMMC。这是盒子类设备最好玩的地方。

一句话流程

线刷 ATV 打底 → 写 fnnas 镜像到 U 盘并改 uEnv.txt 的 fdtfile →
APK 重启进 U 盘 → 浏览器 IP:5666 建账号 → 开 SSH → sudo -i → fnnas-install →
选 x96-max-plus-oc + 分区 16GiB → poweroff 拔盘重启 → 建存储空间。

飞牛 ARM 版由社区维护、官方技术指导，仍带内测性质。硬件批次与镜像版本存在差异，操作前请核对实际配置。刷机风险自负。
